Vos droits RGPD

Tania respecte vos droits RGPD et vous permet de les exercer directement depuis WhatsApp, sans démarche complexe.

Exporter mes données

Envoyez à Tania le message : « exporter mes données ». Vous recevrez immédiatement deux liens sécurisés (valables 24 h) : un fichier JSON complet (toutes vos données) et un fichier CSV (vos factures, ouvrable dans Excel).

Modifier mes informations

Envoyez : « modifier mon profil ». Vous recevrez un lien sécurisé vers votre dashboard pour mettre à jour vos informations entreprise.

Supprimer mon compte

Envoyez : « supprime mon compte ». Tania vous demandera confirmation. Une fois confirmée, vos données personnelles seront supprimées ou anonymisées. Les factures déjà émises peuvent être conservées pour respecter les obligations comptables (10 ans), mais ne seront plus rattachées à votre identité.

Désactiver Tania temporairement

Envoyez : « ne m’envoie plus rien ». Tania cessera de traiter automatiquement vos messages. Vos données restent intactes. Pour réactiver, envoyez « reprendre ».

Contact DPO

Pour toute question relative à vos droits : contact@tania.re. Vous pouvez également contacter la CNIL : www.cnil.fr
